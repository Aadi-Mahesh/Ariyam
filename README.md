## Ariyam ##

This is a student made project using leaflet.js, tailwind and simple JS.

Ariyam is a map of STEM related locations for students interested in the fields to find and check places that might help them learn more about it.

# CURRENT list of features #

- Locations with descriptions
- user location
- dark mode switch
- Search bar
- Type filters

# FUTURE list of features #

- Images for locations
- More developed decription
- more locations
- custom signs for each type of location
